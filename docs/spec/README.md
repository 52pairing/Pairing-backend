## 사용 방법

- 기능을 구현하기 전에 해당 업무구분의 요구사항과 관련 정책을 함께 확인합니다.
- 요구사항의 `관련 요구사항` 컬럼이 두 문서를 연결합니다. 정책의 기준값(수수료율, 라운드 상한, 기한 등)이 요구사항 본문보다 우선입니다.
- 정책이 아직 확정되지 않은 항목은 [policy.md](policy.md#미확정-항목-기준값--정의-필요--비고에-경고-표시)의 미확정 목록에 모아 두었습니다. 이 항목에 의존하는 로직은 확정 전에 구현하지 않습니다.

## 주요 상수 요약

구현 시 자주 참조하는 값입니다. 상세 조건은 각 문서 본문을 확인하십시오.

| 항목 | 값 |
| --- | --- |
| 착수금 수수료 | 1억 미만 클라 3% / 프리 4% · 1억 이상 클라 2% / 프리 4% |
| 성공보수 수수료 | 1억 미만 클라 7% / 프리 6% · 1억 이상 클라 6% / 프리 6% |
| 계약 파기 위약금 | 파기 주체가 상대방 10% + 플랫폼 10% |
| 협상 라운드 상한 | 조건별 15회 |
| 매칭 요청 응답 기한 | 3일 (초과 시 자동 만료 = 거절 처리) |
| 프로젝트 모집 기간 | 기본 2주 + 1주 단위 최대 2회 연장 |
| 재추천 | 무료 1회 (전원 거절/만료 시) · 유료 최대 5회, 프리랜서 1명당 10,000원 |
| 1차 후보 임베딩 풀 | 모집 인원 수 x 3 |
| 프로젝트 예산 | 최소 500만원 ~ 최대 10억 (부가세 별도) |
| 리뷰 | 별점 1~5점 필수 · 리뷰 500자 선택 · 수정/삭제 불가 |
| 데이터 보존 | 완료 건 5년 보관 후 완전 삭제 · 리뷰/별점은 삭제하지 않음 |
| 탈퇴 후 재가입 | 30일 제한 |
| 파일 | 프로필 사진 5MB · 포트폴리오 PDF only(20MB 권장) · 프로젝트 자료 100MB, 10개 |

## 원본 관련 참고

- 원본 요구사항 시트 `G18`(프리랜서 마이페이지 · 예외조건) 셀은 본문이 `=`로 시작해 엑셀에서 `#NAME?`로 표시됩니다. [requirements.md](requirements.md)에는 원문 텍스트를 복구해 실었습니다.
- 정책 문서의 비고 컬럼에는 명세와 정책이 어긋나 정정된 이력이 남아 있습니다. 상충 시 정책 문서를 기준으로 봅니다.
